# Прошивка свистка Elite Energy — пошагово

Пять минут от "коробки" до "работает".

> **Версия v0.2.0 несовместима с v0.1.0 без перепрошивки**: в-поле
> v0.1.0-свистки имеют пустой NVS — после flash v0.2.0 они уйдут в
> recovery-режим (AP `Elite-Setup-XXXX`) и потребуют повторной
> прошивки через web flasher v2.

## Что понадобится

1. Свисток Elite Energy (ESP32-C3 в 3D-печатном корпусе)
2. **Браузер Chrome или Edge** (Firefox / Safari **не поддерживают** Web Serial)
3. USB-C кабель (тот, что для зарядки телефона — но **обязательно с данными**, не "только зарядка")
4. Открытый WiFi с интернетом

## Шаг 1. Подключаем свисток к компьютеру

1. Возьми USB-C кабель.
2. Один конец — в компьютер, другой — в свисток.
3. На свистке должен загореться красный/синий светодиод.

> Если на компьютере выскочило окно "Драйвера устанавливаются" — подожди 30 секунд, оно само закроется. ESP32-C3 использует встроенные драйверы Windows / macOS / Linux, доустанавливать ничего не нужно.

## Шаг 2. Открываем веб-прошивальщик

Открой ссылку: **https://elite.prygoda.xyz/flash/**

Прошивальщик откроется прямо в браузере — ничего скачивать не нужно.

## Шаг 3. Заполняем форму

В v0.2.0 web flasher отдаёт форму с тремя секциями:

1. **Модель инвертора** *(обязательно)* — выбери из списка свой Deye
   (например, `Deye SUN-12K-SG04LP3`). Это единственное обязательное
   поле — без него кнопка `INSTALL` не активируется.
2. **WiFi (опционально)** — SSID + пароль домашней сети. Если оставить
   пустым, свисток после прошивки сразу поднимет setup-сеть
   `Elite-Setup-XXXX` для ввода настроек с телефона.
3. **Solarman облако (опционально)** — 10-значный серийный номер LSW3
   донгла (со старой "пробковой" наклейки). Если оставить пустым,
   данные будут идти только на наш сервер; Solarman-публикатор не
   запустится и не съест ресурсы.

Backend сгенерирует `device_id` + `device_token` + готовый 24 КБ NVS
blob с этими настройками — фронт получит ссылку на blob и подсунет её
ESP-Web-Tools'у вместе с прошивкой.

## Шаг 4. Прошивка

1. Нажми "**INSTALL**" — браузер покажет диалог Web Serial.
2. В выскочившем списке найди порт **USB JTAG/serial debug unit** (или похожее, обычно один такой).
3. Нажми "**Connect**" в окне браузера.
4. Подтверди установку.
5. Подожди 60 секунд — индикатор покажет прогресс. Не отключай USB!

ESP-Web-Tools запишет два куска: собственно прошивку (~1.5 МБ) на
offset `0x0` и сгенерированный NVS blob (24 КБ) на offset `0x9000`.

## Шаг 5. Подключение к WiFi

После прошивки:

1. Свисток сам перезагрузится.
2. Если на шаге 3 ты ввёл WiFi SSID + пароль — свисток сразу
   подключится к домашней сети.
3. Если поле WiFi оставил пустым — на телефоне открой настройки WiFi,
   найди сеть `Elite-Setup-XXXX` (XXXX — последние 4 символа
   MAC-адреса свистка), подключись, пароль `EliteSetup2026`. Откроется
   страница настройки — введи свой реальный SSID и пароль домашней
   сети, свисток перезагрузится и подключится.
4. Если WiFi из NVS не подключается за 5 ретраев — свисток автоматически
   уйдёт в тот же recovery-AP `Elite-Setup-XXXX`.

## Шаг 6. Подключаем к инвертору

См. [`wiring.md`](wiring.md) — там схема и распиновка RJ45-кабеля.

Вкратце:
- Снимаешь стоковый Solarman LSW3 (если он есть).
- Втыкаешь наш свисток в порт **BMS / RS485** инвертора Deye.
- Питание тянется через тот же RJ45 (нашему свистку нужно 12 V с инвертора).

## Шаг 7. Проверка

В течение 30 секунд после подключения свистка к инвертору в нашем дашборде https://elite.prygoda.xyz/admin появятся данные:

- состояние батареи (SoC %)
- мощность от солнечных панелей (W)
- мощность сети (W)
- температура инвертора (°C)

Если данных нет через 2 минуты — открой Issues на https://github.com/samuildotnet/elite-firmware/issues и приложи серийный номер свистка (написан на корпусе) + скриншот веб-прошивальщика после INSTALL.

## Что если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Web Serial не появляется | Проверь что используешь Chrome 89+ или Edge. На Mac иногда нужно дать разрешение в Системных настройках → Конфиденциальность → Доступ к USB-устройствам. |
| Прошивальщик пишет "Failed to enter download mode" | Нажми и держи кнопку BOOT на свистке, потом нажми RESET, потом отпусти BOOT. Затем заново INSTALL. |
| Свисток сразу после прошивки крутится в `Elite-Setup-XXXX` и не выходит из AP | Это значит NVS не записался корректно или WiFi-credentials неверные. Перепрошей через web flasher ещё раз — backend сгенерит свежий NVS blob. |
| Данные не идут на наш дашборд | Проверь логи: открой https://elite.prygoda.xyz/flash/, нажми LOGS после прошивки — увидишь real-time логи. Если есть `MQTT connect failed` — пиши в поддержку. |

## Совсем для упорных: ручная прошивка через esptool

> Этот путь обходит web flasher и **не записывает NVS** — свисток уйдёт
> в recovery-режим. Используй только если умеешь генерить NVS blob
> вручную через `nvs_partition_gen.py`.

```bash
pip install esptool
# 1. Скачай firmware.factory.bin из последнего Release:
#    https://github.com/samuildotnet/elite-firmware/releases/latest
# 2. Прошивай:
# Найди порт:
#   macOS:   ls /dev/cu.usbmodem*
#   Linux:   ls /dev/ttyACM* /dev/ttyUSB*
#   Windows: см. Диспетчер устройств -> Порты (COM и LPT)
esptool.py --chip esp32c3 --port <PORT> \
  --baud 460800 write_flash --flash_mode dio \
  --flash_freq 40m --flash_size 4MB \
  0x0 firmware.factory.bin
# 3. (опционально) Прошить NVS blob отдельно:
esptool.py --chip esp32c3 --port <PORT> \
  --baud 460800 write_flash 0x9000 nvs.bin
```
