Elite Energy // firmware-flasher

Веб-прошивальщик для свистка Elite Energy (ESP32-C3 + MAX3485, для инвертора Deye SUN-12K-SG04LP3).

⚠️ Этот браузер не поддерживает Web Serial API. Открой страницу в Chrome 89+ или Edge на десктопе.

Прошивка

  1. Подключи свисток к компьютеру USB-C кабелем (с данными).
  2. Нажми кнопку ниже.
  3. В окне браузера выбери порт (обычно один — USB JTAG/serial debug unit).
  4. Подожди ~60 секунд.
Браузер не поддерживается — нужен Chrome или Edge. Web Serial доступен только по HTTPS. last build: github releases

WiFi настройка

Прошивка вшивает дефолты SSID=Apple / password=12345678. Если такая сеть не найдена — свисток создаёт точку Elite-Setup-XXXX с паролем EliteSetup2026. Подключись к ней с телефона и введи реальные WiFi-креды в открывшемся captive-portal.

Проблемы при прошивке

  • "Failed to enter download mode" — нажми и держи кнопку BOOT на свистке, кратко нажми RESET, отпусти BOOT. Затем заново INSTALL.
  • Кнопка серая / "браузер не поддерживается" — открой эту страницу в Chrome 89+ или Edge на компьютере.
  • Свисток вообще не появляется в списке портов — кабель без данных (продают как "только зарядка"). Возьми другой.
